# Personal Budget & Expense Tracker

## Project Description
This project is a simple website for tracking personal expenses.
It was created using HTML and CSS.

## Features
- Expense form with name, amount, category, and date.
- Five expense categories: Food, Transport, Rent, Entertainment, and Other.
- Table showing five sample expenses.
- Budgeting tips video section.
- Help section with instructions.
- CSS styling, table row hover effects, and responsive layout.

## Technologies Used
- HTML5
- CSS3
- Git
- GitHub

## How to Open
1. Download or clone this project.
2. Open the index.html file in a web browser.
